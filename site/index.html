What you can investigate

From complaint to evidence

The standard Monitor export summarizes a session. MCS Transcript Analyzer preserves the activity stream and turns it into a support-ready investigation surface.

End-user attribution

Link conversations to the corresponding Dataverse user when identity evidence is available.

Response latency

Track first, average, and slowest replies, plus the delay on each conversation turn.

Agent reasoning

See which topics and actions the orchestrator selected and how the plan progressed.

Tool-call diagnostics

Review connector and AI Builder calls, duration, results, and failures where available.

Flow correlation

Match Power Automate runs to session windows and surface failed or unusually slow actions.

Copilot inventory and credits

Review environments, agents, usage, capacity, spend risk, and audited agent-limit changes.

Consent-based collection

Local sync is automatic. Discovery and verification are not consent; enabling a verified remote source explicitly approves copying and retaining its transcripts in the installed Dataverse environment.

Copilot Credit operations

Usage truth and guarded controls

Add the optional Credits package when makers need usage, capacity, inventory, and controlled agent-limit changes alongside conversation analysis.

Usage and capacity

Review billed and non-billed consumption, available capacity, trends, and collector freshness.

Agent inventory

Find environments and agents even when they have no reported credit usage.

Spend risk

Prioritize agents by current consumption, configured limits, and stop behavior.

Audited changes

Submit guarded agent-limit requests and retain their before, after, and outcome evidence.

Reporting boundary

Credits, conversations, users, and evaluations remain separate evidence. The solution does not claim exact billing allocation between them.

  • Per-user limits are not available
  • Agent-limit changes require the Credit Administrator role

See the Copilot Credit reporting guide for data boundaries, roles, controls, and setup.

Architecture

Runs where the data lives

A sandboxed Dataverse plugin parses finalized transcripts locally or from approved tenant inventory sources. Packaged recurrence flows drain each backlog without an external host or stored access token.

Source

Approved Dataverse environments

Local transcripts and explicitly enabled cross-environment sources verified through a least-privilege ID-only probe.

Processing

Custom API + plugin

Parses identity, turns, latency, plans, tool calls, and outcomes.

Investigation

Conversation Insights

Dataverse tables, model-driven app, forms, views, and searchable JSON.

Additive by default. Finalized transcripts are treated as immutable. Reprocessing is an explicit operation, and the watermark freezes when a batch fails so a bad record cannot be silently skipped.

Known boundaries

Read before production

The solution makes observed platform behavior visible, but it cannot manufacture telemetry that Copilot Studio or Power Automate did not retain.

Detailed traces vary by channel

DialogTracing is emitted in maker-portal design mode, not production Teams or Microsoft 365 Copilot channels. Production analysis uses coarser DynamicPlan events.

Flow matching is time-based

Power Automate flow runs do not carry the transcript conversation ID. Correlation uses overlapping time windows and reports ambiguous matches.

Transcript data is personal data

Restrict table privileges, define retention, and enable auditing according to your privacy and compliance requirements.
